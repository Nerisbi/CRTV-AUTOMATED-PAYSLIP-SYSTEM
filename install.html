🚀 Installation Steps

Step 1: Download the ZIP file by clicking the button above
Step 2: Extract the ZIP file to a folder (e.g., C:\CRTV-Payslip-System)
Step 3: Open Command Prompt as Administrator and run:
cd C:\CRTV-Payslip-System
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
Step 4: Run the application:
python run_clean_ui.py

📧 First Time Setup

  • Prepare your payslip PDF file
  • Create Excel file with columns: Name, Email, Page (add ID column recommended)
  • Prepare company stamp image (PNG/JPG)
  • Configure Gmail settings if needed
