CRTV Automated Payslip Distribution System
==========================================

🚀 QUICK START GUIDE

INSTRUCTIONS:
1. Double-click CRTV-Payslip-System.exe to launch
2. Prepare your files:
   - Put employee Excel file in: input/employees.xlsx
   - Put company stamp in: input/Stamp.png
   - Put all payslip PDFs in: input/payslips/
3. In the application:
   - Click "Upload PDF" → Select your payslips folder
   - Click "Validate Files" to ensure everything is ready
   - Click "Send Payslips" → Preview → Start Sending

📋 REQUIREMENTS:
- Windows 10 or later
- Internet connection for sending emails
- Gmail account configured in the system

📧 EMAIL SETUP:
The system is pre-configured to send emails via Gmail.
Contact IT department if email sending fails.

🔍 TROUBLESHOOTING:
- If the program doesn't start: Run as Administrator
- If emails fail: Check internet connection and Gmail settings
- If payslips not found: Ensure PDFs contain matricule numbers

💾 FILE FORMATS:
- Excel: Must contain columns "Name", "Matricule", "Email"
- PDFs: Must contain matricule numbers in the content
- Stamp: PNG format recommended

For technical support, contact CRTV IT Department.
